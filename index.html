LABORATORIO INTERACTIVO

Ahora te toca experimentar

Prueba el ejemplo «Seno suave», escucha el resultado y luego cambia la expresión. ¿Qué sucede cuando modificas la amplitud?

Para comenzar: elige «Seno suave» entre los ejemplos y presiona ▶ Reproducir. El eje horizontal representa el recorrido temporal y el valor vertical determina la altura de las notas.

Escribe y = f(x). El eje x es el tiempo y el eje y es el tono (y = 0 es la nota base; cada unidad sube los semitonos que indiques en Ajustes). Toca la gráfica para elegir desde dónde sonar.
Trigonometría: sin, cos, tan, sec, csc, cot, asin, acos, atan, atan2(y,x), sinh, cosh, tanh, asinh, acosh, atanh, rad(grados), deg(radianes).
Ondas (periodo 2π, como sin): square, saw, tri, pulse(x, ancho de 0 a 1), sinc, noise.
Potencias y logaritmos: sqrt, cbrt, root(x,n), exp, exp2, expm1, pow, ln, log (base 10, o log(x,base)), log2, logb(x,b), log1p, hypot.
Redondeo y signo: abs, floor, ceil, round(x,decimales), trunc, frac, sign, mod(a,b) y el operador %.
Combinatoria y números: fact(n) o n!, gamma, ncr(n,k), npr(n,k), gcd, lcm, fib, isprime, erf.
Curvas útiles: gauss, sigmoid, relu, heaviside, smoothstep(x,a,b), lerp(a,b,t), clamp(x,a,b), step(x,a), min, max, avg.
Lógica y selección: pick(i, a, b, c…), if(cond, a, b), and, or, not, y comparaciones < > <= >= == !=.
Ayudas musicales: semi(n) (semitonos → y), hz(frecuencia) (Hz → y).
Constantes: pi, tau, e, phi, sqrt2, ln2, ln10, inf, rest (silencio). Trigonometría en grados: sind, cosd, tand.
Notación: puedes escribir f(x)=x²−4x+3, y = x^2 - 4x + 3 o x2-4x+3 (la x seguida de un número se toma como potencia). También se aceptan 2x, √x, π, × y ÷.
Se pueden pegar nombres y variables: xsin(3x) es x·sin(3x), sin3x es sin(3x) y cos2 es cos(2). Además, e-0.2x (pegado, sin espacios) se lee como e^(−0.2x); si quieres restar, escribe e - 0.2x con espacios.
